# GreenLoop Melbourne

GreenLoop Melbourne is a Vue 3 frontend foundation for the FIT5032 A1.2 Basic Application
Development project. It is a non-profit recycling information concept for Melbourne residents.

## Technology

- Vue 3 with the Composition API and `<script setup>`
- Vite
- Vue Router
- Bootstrap 5
- JavaScript and CSS

## Local development

```sh
npm install
npm run dev
```

Open the local URL displayed by Vite (normally `http://localhost:5173`).

## Production build

```sh
npm run build
```

This initial version provides routing, responsive navigation, page structure, reusable components,
and starter data only. Search, validation, external services, authentication, and ratings are not
implemented.
